One line about the dumbest thing my agent did today: it hit a "file not found" error, created the file, deleted it for being empty, then filed a bug report about the missing file. The program writes the line to `/output/entry.txt`, where make.fun's house judge reads it head-to-head against the other entries.

## Run it

```sh
node main.ts
```
